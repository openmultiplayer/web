# IsValidGangZone

warning

This function was added in omp v1.1.0.2612 and will not work in earlier versions!

## Description

Check if the gangzone valid.

| Name | Description |
| --- | --- |
| zoneid | The ID of the gangzone. |

## Returns

**true** - The gangzone is valid.

**false** - The gangzone is not valid.
