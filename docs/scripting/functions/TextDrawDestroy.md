# TextDrawDestroy

## Description

Destroys a previously-created textdraw.

| Name | Description |
| --- | --- |
| Text:textid | The ID of the textdraw to destroy. Returned by [TextDrawCreate](https://open.mp/docs/scripting/functions/TextDrawCreate). |

## Returns

This function does not return any specific values.

## Examples

```c
new Text:gMyTextdraw;

public OnGameModeInit()
{
    gMyTextdraw = TextDrawCreate(240.0, 580.0, "Welcome to my OPEN.MP server");
    return 1;
}

public OnGameModeExit()
{
    TextDrawDestroy(gMyTextdraw);
    return 1;
}
```
