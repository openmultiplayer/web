# IsMenuDisabled

warning

This function was added in omp v1.1.0.2612 and will not work in earlier versions!

## Description

Checks if a menu is disabled.

| Name | Description |
| --- | --- |
| Menu:menuid | The ID of the menu to check. |

## Returns

Returns **true** if the menu is disabled, otherwise **false**.
