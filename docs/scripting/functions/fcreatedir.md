# fcreatedir

warning

This function was added in omp v1.1.0.2612 and will not work in earlier versions!

## Description

Create a directory.

| Name | Description |
| --- | --- |
| const dirname\[\] | The name of the directory to create, optionally including a full path. |

## Returns

**true** on success, **false** on failure.

## Examples

```c
if (fcreatedir("logs"))
{
    // Success
    printf("The directory \"logs\" created successfully.");
}
else
{
    // Error
    print("Failed to create the directory \"logs\"");
}
```

## Notes

tip

To delete the directory again, use [fremove](https://open.mp/docs/scripting/functions/fremove). The directory must be empty before it can be removed.
