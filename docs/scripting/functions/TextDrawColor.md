# TextDrawColor

## Description

Sets the text color of a textdraw

| Name | Description |
| --- | --- |
| Text:textid | The ID of the textdraw to change the color of.. |
| textColour | The color to set the textdraw to. |

## Returns

This function does not return any specific values.

## Examples

```c
new Text:gMyTextdraw;

public OnGameModeInit()
{
    gMyTextdraw = TextDrawCreate(123.0, 123.0, "Example");
    TextDrawColor(gMyTextdraw, 0x000000FF);
    return 1;
}
```

## Notes

tip

You can also use [GameText colors](https://open.mp/docs/scripting/resources/gametextstyles) in textdraws.

note

If the TextDraw is already shown, it must be re-shown ([TextDrawShowForAll](https://open.mp/docs/scripting/functions/TextDrawShowForAll)/[TextDrawShowForPlayer](https://open.mp/docs/scripting/functions/TextDrawShowForPlayer)) for the changes of this function to take effect.
