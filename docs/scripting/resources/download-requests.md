# Download Request Types

note

These definitions are used by [OnPlayerRequestDownload](https://open.mp/docs/scripting/callbacks/OnPlayerRequestDownload) callback.

| ID | Definition |
| --- | --- |
| \-1 | UNKNOWN\_DOWNLOAD\_REQUEST |
| 0 | DOWNLOAD\_REQUEST\_EMPTY |
| 1 | DOWNLOAD\_REQUEST\_MODEL\_FILE |
| 2 | DOWNLOAD\_REQUEST\_TEXTURE\_FILE |
