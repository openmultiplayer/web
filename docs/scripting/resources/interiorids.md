# interiorids

## How to get the Interior ID

* * *

If you are inside an interior type

```c
/interior
```

and you'll see the ID of the interior universe. Now you can safely use [SetPlayerInterior](https://open.mp/docs/scripting/functions/SetPlayerInterior) and [LinkVehicleToInterior](https://open.mp/docs/scripting/functions/LinkVehicleToInterior) before using [SetPlayerPos](https://open.mp/docs/scripting/functions/SetPlayerPos).
