# File Modes

note

These file modes are used by [fopen](https://open.mp/docs/scripting/functions/fopen).

| Mode | Description |
| --- | --- |
| io\_read | Reads from the file. |
| io\_write | Write in the file, or create the file if it does not exist. Erases all existing contents. |
| io\_readwrite | Reads the file or creates it if it doesn't already exist. |
| io\_append | Appends (adds) to file, write-only. If the file does not exist, it is created. |
