# Material Text Alignments

info

There are two kinds of parameters for [SetObjectMaterialText](https://open.mp/docs/scripting/functions/SetObjectMaterialText) - material text alignments and material text sizes. Text alignments are listed on this page.

| Value | Definition |
| --- | --- |
| 0 | OBJECT\_MATERIAL\_TEXT\_ALIGN\_LEFT |
| 1 | OBJECT\_MATERIAL\_TEXT\_ALIGN\_CENTER |
| 2 | OBJECT\_MATERIAL\_TEXT\_ALIGN\_RIGHT |
