# Types Of Race Checkpoints

note

These definitions are used by [SetPlayerRaceCheckpoint](https://open.mp/docs/scripting/functions/SetPlayerRaceCheckpoint).

| Definition | Value | Description |
| --- | --- | --- |
| UNKNOWN\_CP\_TYPE | \-1 |  |
| CP\_TYPE\_GROUND\_NORMAL | 0 | Normal |
| CP\_TYPE\_GROUND\_FINISH | 1 | Finish |
| CP\_TYPE\_GROUND\_EMPTY | 2 | Nothing (only the checkpoint without anything on it) |
| CP\_TYPE\_AIR\_NORMAL | 3 | Air normal |
| CP\_TYPE\_AIR\_FINISH | 4 | Air finish |
| CP\_TYPE\_AIR\_ROTATING | 5 | Air (rotates and stops) |
| CP\_TYPE\_AIR\_STROBING | 6 | Air (increases, decreases and disappears) |
| CP\_TYPE\_AIR\_SWINGING | 7 | Air (swings down and up) |
| CP\_TYPE\_AIR\_BOBBING | 8 | Air (swings up and down) |
