# Angle Modes

note

These angle modes are used by [floatsin](https://open.mp/docs/scripting/functions/floatsin), [floatcos](https://open.mp/docs/scripting/functions/floatcos), and [floattan](https://open.mp/docs/scripting/functions/floattan).

| Mode | Description |
| --- | --- |
| radian | The angle will be in radians. |
| degrees | The angle will be in degrees. |
| grades | The angle will be in grades. |
