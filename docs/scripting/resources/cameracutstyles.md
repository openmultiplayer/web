# Camera Cut Styles

info

Camera cut styles are used by natives such as [SetPlayerCameraLookAt](https://open.mp/docs/scripting/functions/SetPlayerCameraLookAt), [InterpolateCameraPos](https://open.mp/docs/scripting/functions/InterpolateCameraPos) and [InterpolateCameraLookAt](https://open.mp/docs/scripting/functions/InterpolateCameraLookAt).

## Cut Styles

| ID | Style | Description |
| --- | --- | --- |
| 1 | CAMERA\_MOVE | The camera position and/or target will move to its new value over time. |
| 2 | CAMERA\_CUT | The camera position and/or target will move to its new value instantly. |
