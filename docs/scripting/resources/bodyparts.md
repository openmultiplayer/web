# Body parts

info

The following entries are body part IDs which can be used by [OnPlayerGiveDamage](https://open.mp/docs/scripting/callbacks/OnPlayerGiveDamage), [OnPlayerTakeDamage](https://open.mp/docs/scripting/callbacks/OnPlayerTakeDamage) and [OnPlayerGiveDamageActor](https://open.mp/docs/scripting/callbacks/OnPlayerGiveDamageActor).

* * *

| ID | Body Part |
| --- | --- |
| 3 | Torso |
| 4 | Groin |
| 5 | Left arm |
| 6 | Right arm |
| 7 | Left leg |
| 8 | Right leg |
| 9 | Head |

* * *

note

These IDs are not 100% confirmed, and are not defined in any SA-MP includes - they must be defined by the scripter. It is unknown if IDs 0, 1 and 2 have any use.
