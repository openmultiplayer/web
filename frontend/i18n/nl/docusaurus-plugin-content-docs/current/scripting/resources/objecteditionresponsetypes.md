sidebar_label: "Objectbewerkings‑responstypen"
---

:::info

Gebruikt door [OnPlayerEditObject](../callbacks/OnPlayerEditObject).

:::

| Waarde | Definitie            | Beschrijving                                                  |
| ------ | -------------------- | ------------------------------------------------------------- |
| 0      | EDIT_RESPONSE_CANCEL | Speler annuleerde wijzigingen (ESC)                           |
| 1      | EDIT_RESPONSE_FINAL  | Speler bevestigde wijzigingen (Save)                          |
| 2      | EDIT_RESPONSE_UPDATE | Speler verschoof alleen het object (bewerken is niet gestopt) |
