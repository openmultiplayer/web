## الوصف {#description}

يحتوي ملف `sa-mp.cfg` على إعدادات برنامج SA-MP على جهازك. ستجده داخل مجلد `My Documents\GTA San Andreas User Files\SAMP` الخاص بحسابك في Windows. يمكنك تعديله باستخدام محرّر نصوص مثل المفكرة.

## الخيارات {#options}

| الخيار | الوصف |
| --- | --- |
| **pagesize** | عدد أسطر الدردشة الظاهرة، من `10` إلى `20` سطرًا. القيمة الافتراضية `10`. يمكنك تغييره داخل اللعبة بالأمر `/pagesize`. |
| **fpslimit** | الحد الأقصى [لعدد الإطارات في الثانية](https://en.wikipedia.org/wiki/Frame_rate)، ويُطبّق عند تفعيل محدّد الإطارات في قائمة GTA:SA. القيم المقبولة من `20` إلى `90`، والافتراضية في SA-MP هي `50`. يمكنك تغييره بالأمر `/fpslimit`. |
| **disableheadmove** | التحكم في حركة رؤوس اللاعبين باتجاه نظرهم. القيمة `1` توقف الحركة، و`0` تسمح بها. يمكنك تبديله بالأمر `/headmove`. |
| **timestamp** | إظهار وقت جهازك بجانب رسائل الدردشة بالقيمة `1`، أو إخفاؤه بالقيمة `0`. يمكنك تبديله بالأمر `/timestamp`. |
| **ime** | دعم إدخال النص وتبديل اللغة باستخدام محرّر أسلوب الإدخال (IME) في الدردشة. القيمة `1` تفعّله، و`0` تعطّله. |
| **multicore** | السماح لبرنامج SA-MP باستخدام عدة أنوية للمعالج. القيمة الافتراضية `1` تفعّل ذلك. جرّب `0` إذا واجهت مشكلات في حركة الفأرة. |
| **directmode** | استخدام طريقة أبطأ لرسم نص الدردشة مباشرةً على الشاشة إذا واجهت مشكلات في عرضه. القيمة `1` تفعّل هذه الطريقة، و`0` تعطّلها. |
| **audiomsgoff** | القيمة `1` تخفي رسائل `Audio Stream: [URL]` التي تظهر عند تشغيل الخادم بثًا صوتيًا. يمكنك تبديل هذا الإعداد بالأمر `/audiomsg`. |
| **audioproxyoff** | القيمة `1` تمنع استخدام الخادم الوكيل المحدّد في خيارات الإنترنت في Windows لتشغيل البث الصوتي في SA-MP. |
| **nonametagstatus** | القيمة `0`، وهي الافتراضية، تُظهر رمز الساعة الرملية بجانب اسم اللاعب الذي أوقف لعبته مؤقتًا. يمكنك تغيير هذا الإعداد بالأمر `/nametagstatus`. |
| **fontface** | تغيير خط الدردشة ومربعات الحوار ولوحة النتائج، مثل `fontface="Comic Sans MS"`. هذا الخيار غير مدعوم رسميًا وقد يسبب مشكلات. |
| **fontweight** | القيمة `0` تختار الخط العريض، وهي الافتراضية، والقيمة `1` تختار الخط العادي. |
