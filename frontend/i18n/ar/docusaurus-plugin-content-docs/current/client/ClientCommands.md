## الأوامر {#commands}

هذه أوامر مدمجة في برنامج اللعبة، وقد يضيف الخادم الذي تلعب عليه أوامر أخرى خاصة به.

| الأمر | الوصف |
| --- | --- |
| `/quit` أو `/q` | الخروج من اللعبة. كلاهما يؤدي الوظيفة نفسها. |
| `/save` | حفظ موقعك الحالي في ملف `savedpositions.txt` داخل مجلد ملفات المستخدم، لتتمكن من استخدامه لاحقًا في السكربتات. |
| `/rs` | اختصار لـ Raw Save. يشبه `/save`، لكنه يحفظ الموقع وزاوية الاتجاه فقط في `rawpositions.txt` داخل مجلد ملفات المستخدم، دون معلومات إضافية مثل فئة الشخصية أو الأسلحة. |
| `/interior` | عرض معرّف المنطقة الداخلية الحالية في نافذة الدردشة. |
| `/vw` | عرض معرّف العالم الافتراضي الحالي في نافذة الدردشة. |
| `/fpslimit` | تعيين الحد الأقصى لعدد الإطارات في الثانية بين `20` و`90`؛ والقيمة الافتراضية `50`. لا يؤثر الأمر إذا كان محدّد الإطارات معطّلًا في إعدادات الرسومات. رفع الحد يسمح بعرض إطارات أكثر وقد يجعل الحركة أكثر سلاسة. يقابل الخيار `fpslimit` في `sa-mp.cfg`. |
| `/pagesize` | تعيين عدد أسطر الدردشة الظاهرة، من `10` إلى `20` سطرًا. القيمة الافتراضية `10`. يقابل الخيار `pagesize`. |
| `/headmove` | إظهار حركة رؤوس اللاعبين باتجاه نظرهم أو إخفاؤها لديك. هذا التغيير محلي؛ لذا سيظل اللاعبون الآخرون يرون حركة رأسك. يقابل الخيار `disableheadmove`. |
| `/timestamp` | إظهار الوقت بجانب رسائل الدردشة أو إخفاؤه. الوقت المعروض هو وقت جهازك، وليس وقت الخادم. يقابل الخيار `timestamp`. |
| `/dl` | إظهار بيانات تشخيص المركبات أو إخفاؤها. تشمل المعرّف والطراز ومقدار السلامة وحالة التحميل المسبق والمسافة من اللاعب والمقطورة والمقاعد المتاحة والموقع الحالي وموقع الظهور. |
| `/nametagstatus` | إظهار رمز الساعة الرملية بجانب اسم اللاعب الذي أوقف لعبته مؤقتًا أو إخفاؤه. يشمل ذلك تصغير النافذة بـ `Alt+Tab`، وفتح قائمة الإيقاف بـ `Esc`، وانقطاع الاتصال بسبب تعطل اللعبة أو انتهاء المهلة، والتقاط صورة تجمّد اللعبة لأكثر من ثلاث ثوانٍ. الميزة مفعّلة افتراضيًا، ويقابلها الخيار `nonametagstatus`. |
| `/mem` | عرض مقدار الذاكرة المستخدمة حاليًا، مع أنه يعرض عادةً `128 MB` فقط. |
| `/audiomsg` | إظهار رسالة رابط البث الصوتي في الدردشة أو إخفاؤها عند تشغيله. يقابل الخيار `audiomsgoff`. |
| `/fontsize` | تغيير حجم خط الواجهة، بما فيها الدردشة ومربعات الحوار. القيم المقبولة من `-3` إلى `5`. |
| `/ctd` | تفعيل عرض بيانات تشخيص هدف كاميرا اللاعب. أُضيف في `SA-MP 0.3.7 RC2`. |
| `/rcon` | تنفيذ أوامر نظام إدارة الخادم المدمج RCON، وهو اختصار لـ [التحكم عن بُعد](../server/ControllingServer#using-rcon). |
| `/hudscalefix` | تفعيل تصحيح أبعاد الرادار على الشاشات العريضة أو تعطيله، حتى لا يظهر الرادار الدائري بشكل بيضاوي. أُضيف في `SA-MP 0.3.7 R3`، ويقابل الخيار `nohudscale`. |

## ملف sa-mp.cfg {#file-sa-mpcfg}

| الخيار | الوصف |
| --- | --- |
| `pagesize` | انظر `/pagesize` أعلاه. |
| `fpslimit` | انظر `/fpslimit` أعلاه. |
| `disableheadmove` | انظر `/headmove` أعلاه. |
| `timestamp` | انظر `/timestamp` أعلاه. |
| `ime` | دعم إدخال النص وتبديل اللغة باستخدام محرّر أسلوب الإدخال (IME) في الدردشة. القيمة `1` تفعّله، و`0` تعطّله. |
| `audiomsgoff` | انظر `/audiomsg` أعلاه. |
| `multicore` | السماح لبرنامج SA-MP باستخدام عدة أنوية للمعالج. القيمة الافتراضية `1` تفعّل ذلك. جرّب `0` إذا واجهت مشكلات في حركة الفأرة. |
| `directmode` | استخدام طريقة أبطأ لرسم نص الدردشة مباشرةً على الشاشة، للمساعدة في حل مشكلات عرضه. القيمة `1` تفعّلها، و`0` تعطّلها. |
| `audioproxyoff` | عند تعيينه إلى `1`، لا يُستخدم الخادم الوكيل المحدّد في خيارات الإنترنت في Windows لتشغيل البث الصوتي في SA-MP. |
| `nonametagstatus` | انظر `/nametagstatus` أعلاه. |
| `fontface` | تغيير خط الدردشة ومربعات الحوار ولوحة النتائج، مثل `fontface="Comic Sans MS"`. هذا الخيار غير مدعوم رسميًا وقد يسبب مشكلات. |
| `fontweight` | اختيار خط دردشة عريض بالقيمة `0`، وهي الافتراضية، أو عادي بالقيمة `1`. |
| `nohudscale` | أُضيف في `SA-MP 0.3.7 R3`. انظر `/hudscalefix` أعلاه. |
