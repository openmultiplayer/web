## Deskripsi

`sa-mp.cfg` adalah file konfigurasi klien yang memungkinkan Anda mengubah pengaturan terkait SA-MP. File ini berada di folder 'My Documents\\GTA San Andreas User Files\\SAMP' pada akun pengguna Windows Anda. File ini dapat diedit dengan editor teks seperti Notepad.

## Opsi

| Opsi               | Deskripsi                                                                                                                                                                                          |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **pagesize**       | Lihat /pagesize.                                                                                                                                                                                   |
| **fpslimit**       | Lihat /fpslimit.                                                                                                                                                                                   |
| **disableheadmove** | Lihat /headmove.                                                                                                                                                                                   |
| **timestamp**      | Lihat /timestamp.                                                                                                                                                                                  |
| **ime**            | Ini mengatur apakah kotak chat mendukung pengeditan teks dengan Input Method dan pergantian bahasa. 1 mengaktifkan IME, 0 menonaktifkannya.                                                       |
| **audiomsgoff**    | Lihat /audiomsg.                                                                                                                                                                                   |
| **multicore**      | Mengaktifkan atau menonaktifkan penggunaan beberapa inti CPU oleh klien SA-MP. Defaultnya adalah `1` (menggunakan beberapa inti CPU). Atur ke `0` jika mengalami masalah dengan mouse.             |
| **directmode**     | Memungkinkan pemain yang mengalami masalah saat menggambar teks chat menggunakan mode rendering teks langsung ke layar yang lebih lambat. 0 untuk menonaktifkan, 1 untuk mengaktifkan.            |
| **audioproxyoff**  | Jika opsi ini diatur ke `1` dan ada server proxy di Pengaturan Internet Windows, proxy tidak akan digunakan saat memutar audio stream di SA-MP.                                                   |
| **nonametagstatus** | Lihat /nametagstatus.                                                                                                                                                                             |
| **fontface**       | Ditambahkan pada versi 0.3.7. Memungkinkan Anda mengubah font chat, dialog, dan papan skor, misalnya `fontface="Comic Sans MS"`. Tidak didukung secara resmi dan dapat menyebabkan masalah.      |
| **fontweight**     | Ditambahkan pada versi 0.3.7. Opsi ini mengatur apakah font chat dicetak tebal. 0 = TEBAL (default) dan 1 = NORMAL.                                                                                |
| **nohudscalefix**  | Opsi ini mengaktifkan atau menonaktifkan perbaikan skala radar dan juga dapat diubah dalam game dengan perintah client-side /hudscalefix.                                                         |
