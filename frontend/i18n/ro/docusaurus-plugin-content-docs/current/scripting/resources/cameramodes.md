## Descriere

O listă a posibilelor moduri de cameră pentru a fi utilizate [GetPlayerCameraMode](../functions/GetPlayerCameraMode).

:::note

S-ar putea să existe încă mai multe ID-uri utilizabile ascunse în joc și unele ID-uri sunt utilizate pentru mai multe situații.

:::

## Lista

| ID  | Definitie                  | Mode                                                                                                                                                         |
| --- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 3   | CAM_MODE_BEHINDCAR         | Cameră de tren / tramvai.                                                                                                                                    |
| 4   | CAM_MODE_FOLLOWPED         | Urmați caracterul (normal în spatele camerei playerului).                                                                                                    |
| 7   | CAM_MODE_SNIPER            | Lunetist care țintește.                                                                                                                                      |
| 8   | CAM_MODE_ROCKETLAUNCHER    | Lansator de rachete care vizează.                                                                                                                            |
| 15  | CAM_MODE_FIXED             | Cameră fixă (care nu se mișcă) - utilizată pentru Pay 'n' Spray, camera de urmărire, acordarea magazinelor, intrarea în clădiri, cumpărarea de alimente etc. |
| 16  | CAM_MODE_1STPERSON         | Cameră frontală pentru vehicul, cameră laterală pentru bicicletă.                                                                                            |
| 18  | CAM_MODE_CAM_ON_A_STRING   | Mașină normală (+ skimmer + elicopter + avion), mai multe distanțe variabile.                                                                                |
| 22  | CAM_MODE_BEHINDBOAT        | Cameră normală pentru bărci.                                                                                                                                 |
| 46  | CAM_MODE_CAMERA            | Ținta cu arma a camerei.                                                                                                                                     |
| 51  | CAM_MODE_ROCKETLAUNCHER_HS | Lansatorul de rachete care caută căldură vizează.                                                                                                            |
| 53  | CAM_MODE_AIMWEAPON         | Țintind orice altă armă.                                                                                                                                     |
| 55  | CAM_MODE_AIMWEAPON_FROMCAR | Cameră vehicul pasager cu vehicul.                                                                                                                           |
| 56  | CAM_MODE_DW_HELI_CHASE     | Camera de urmărire: elicopter / vedere păsări.                                                                                                               |
| 57  | -                          | Camera de urmărire: cameră de la sol, se apropie foarte repede. (Similar cu 56, dar la sol.)                                                                 |
| 58  | -                          | Cameră de urmărire: zbura orizontală pe lângă vehicul.                                                                                                       |
| 59  | -                          | Cameră de urmărire (numai pentru vehiculele aeriene): cameră de la sol, cu ochii în sus spre vehiculul aerian.                                               |
| 62  | -                          | Camera de urmărire (numai pentru vehiculele aeriene): zboară verticală pe lângă vehiculul aerian.                                                            |
| 63  | -                          | Cameră de urmărire (numai pentru vehiculele aeriene): zbura orizontală pe lângă vehiculul aerian (similar cu 58 și 62).                                      |
| 64  | -                          | Cameră de urmărire (numai pentru vehiculele aeriene): cameră focalizată pe pilot, similar cu apăsarea tastei LOOK_BEHIND pe jos, dar în vehiculul aerian.    |
