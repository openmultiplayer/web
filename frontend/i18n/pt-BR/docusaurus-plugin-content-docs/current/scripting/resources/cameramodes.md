## Descrição

Lista de modos de câmeras que podem ser utilizados com [GetPlayerCameraMode](../functions/GetPlayerCameraMode).

:::note

Podem haver mais IDs utilizáveis escondidos no jogo e alguns IDs são usados para mais que uma situação.

:::

## Lista

| ID  | Definição                  | Modo                                                                                                                                                                    |
| --- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 3   | CAM_MODE_BEHINDCAR         | Train/tram camera.                                                                                                                                                      |
| 4   | CAM_MODE_FOLLOWPED         | Camera normal que segue o jogador.                                                                                                                                      |
| 7   | CAM_MODE_SNIPER            | Mira de Sniper.                                                                                                                                                         |
| 8   | CAM_MODE_ROCKETLAUNCHER    | Mira de uma Rocket Launcher.                                                                                                                                            |
| 15  | CAM_MODE_FIXED             | Câmera Fixa (Não se move) - usada para Pay 'n' Spray, câmera de perseguição, shops de tunagem, entrando em construções, comprando comida, etc.                          |
| 16  | CAM_MODE_1STPERSON         | Câmera frontal do veículo, câmera lateral da bicicleta.                                                                                                                 |
| 18  | CAM_MODE_CAM_ON_A_STRING   | Carro normal (+skimmer+helicopter+airplane), diversas variações de distância.                                                                                           |
| 22  | CAM_MODE_BEHINDBOAT        | Câmera normal do bote.                                                                                                                                                  |
| 46  | CAM_MODE_CAMERA            | Câmera da mira de uma arma normal.                                                                                                                                      |
| 51  | CAM_MODE_ROCKETLAUNCHER_HS | Mira de Heat-seeking Rocket Launcher.                                                                                                                                   |
| 53  | CAM_MODE_AIMWEAPON         | Mirando qualquer outra ara.                                                                                                                                             |
| 55  | CAM_MODE_AIMWEAPON_FROMCAR | Câmera drive-by de passageiros no veículo.                                                                                                                              |
| 56  | CAM_MODE_DW_HELI_CHASE     | Câmera de perseguição: visão de helicoptero.                                                                                                                            |
