## Opis

`sa-mp.cfg` to plik konfiguracyjny klienta, który pozwala zmieniać ustawienia związane z SA-MP. Znajduje się w folderze „Moje dokumenty\\GTA San Andreas User Files\\SAMP” na koncie użytkownika Windows. Można go edytować za pomocą edytora tekstu, takiego jak Notatnik.

## Opcje

| Opcja                | Opis                                                                                                                                                                                                                               |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **pagesize**        | Zobacz /pagesize.                                                                                                                                                                                                                  |
| **fpslimit**        | Zobacz /fpslimit.                                                                                                                                                                                                                  |
| **disableheadmove** | Zobacz /headmove.                                                                                                                                                                                                                  |
| **timestamp**       | Zobacz /timestamp.                                                                                                                                                                                                                 |
| **ime**             | Kontroluje, czy okno czatu obsługuje edycję tekstu metodą wprowadzania i zmianę języka. Wartość 1 włącza IME, a 0 je wyłącza.                                                                                                       |
| **audiomsgoff**     | Zobacz /audiomsg.                                                                                                                                                                                                                  |
| **multicore**       | Pozwala włączyć lub wyłączyć używanie wielu rdzeni procesora przez klienta SA-MP. Domyślna wartość to `1` (używa wielu rdzeni). Ustaw `0`, jeśli występują problemy z myszą.                                                       |
| **directmode**      | Pozwala graczom z problemami z wyświetlaniem tekstu czatu użyć wolniejszego trybu renderowania tekstu bezpośrednio na ekranie. 0 wyłącza, 1 włącza.                                                                                |
| **audioproxyoff**   | Jeśli ta opcja jest ustawiona na `1` i w ustawieniach internetowych systemu Windows skonfigurowano serwer proxy, nie będzie on używany podczas odtwarzania strumieni audio w SA-MP.                                                |
| **nonametagstatus** | Zobacz /nametagstatus.                                                                                                                                                                                                             |
| **fontface**        | Dodano w wersji 0.3.7. Pozwala zmienić czcionkę czatu, dialogów i tablicy wyników, np. `fontface="Comic Sans MS"`. Opcja nie jest oficjalnie wspierana i może powodować problemy.                                                   |
| **fontweight**      | Dodano w wersji 0.3.7. Ta opcja przełącza pogrubienie czcionki czatu. 0 = POGRUBIONA (domyślnie), a 1 = NORMALNA.                                                                                                                   |
| **nohudscalefix**   | Ta opcja włącza lub wyłącza poprawkę skali radaru. Można ją również zmienić w grze za pomocą komendy klienta /hudscalefix.                                                                                                         |
