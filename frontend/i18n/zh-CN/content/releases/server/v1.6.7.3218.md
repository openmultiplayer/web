## 变更内容（自 v1.5.8.3079 起）

### 服务器运行与网络

- 新增 `artwork.show_crc_logs` 配置项，可在需要时开启 TXD 与 DFF 文件的 CRC 日志记录；该选项默认关闭。[#1164](https://github.com/openmultiplayer/open.mp/pull/1164)
- 修复了服务器配置中的环境变量替换问题，数值型与布尔型配置项也不例外。[#1195](https://github.com/openmultiplayer/open.mp/pull/1195)
- 修复了 `reloadbans`：重新载入的封禁现在会重新由网络层执行，命中的在线玩家也会一并被移除。[#1276](https://github.com/openmultiplayer/open.mp/pull/1276)
- 修复了踢出玩家后误报“服务器已满”的问题，拒绝无效的连接丢失（connection lost）数据包，并对无效的连接尝试施以临时封禁，以减少日志刷屏。[#1209](https://github.com/openmultiplayer/open.mp/pull/1209), [#1173](https://github.com/openmultiplayer/open.mp/pull/1173)
- 修复了服务器刚启动时发起的连接因无效的网络 cookie 而被拒绝的问题。[#1213](https://github.com/openmultiplayer/open.mp/pull/1213)
- 修复了插件在发送前读取广播 RPC 载荷时该载荷被截短的问题，此问题会影响天气切换、消息发送与游戏文本等功能。[#1215](https://github.com/openmultiplayer/open.mp/pull/1215)
- 修复了 Linux 服务器在无终端环境下（例如通过 `nohup` 运行）关闭时卡死或崩溃的问题。[#1203](https://github.com/openmultiplayer/open.mp/pull/1203)
- 车辆重生时现在会重置喷漆（paintjob）。[#1213](https://github.com/openmultiplayer/open.mp/pull/1213)

### 脚本与组件

- 修复了 Pawn `format()` 中 `%q` 的转义问题、以字符串方式读取不存在的控制台变量时的崩溃，以及由非法 `SetTimerEx` 参数引发的崩溃。[#1159](https://github.com/openmultiplayer/open.mp/pull/1159), [#1171](https://github.com/openmultiplayer/open.mp/pull/1171), [#1223](https://github.com/openmultiplayer/open.mp/pull/1223)
- 修复了退出观战模式后无法重生的问题，并让 `TogglePlayerSpectating` 能可靠地重新开启观战。[#1187](https://github.com/openmultiplayer/open.mp/pull/1187), [#1092](https://github.com/openmultiplayer/open.mp/pull/1092)
- 调整了主脚本的卸载流程：组件现在会在脚本卸载完成后再行重置，避免回调与计时器仍引用已卸载的脚本。[#1190](https://github.com/openmultiplayer/open.mp/pull/1190)
- 为未指定文件名便调用脚本加载类控制台命令的情况补充了用法提示，并为缺失旧版插件的情况给出了更明确的错误信息。[#1032](https://github.com/openmultiplayer/open.mp/pull/1032), [#1273](https://github.com/openmultiplayer/open.mp/pull/1273)
- 新增了对物体与附着物体编辑状态的独立校验，并会依据当前生效的编辑模式校验客户端返回的编辑结果。[#1188](https://github.com/openmultiplayer/open.mp/pull/1188)
- 修复了 `AttachPlayerObjectToObject`（含其 C API 调用路径）忽略 `syncRotation` 参数的问题。[#1163](https://github.com/openmultiplayer/open.mp/pull/1163)
- 修复了 C API 中销毁帮派区域（gang zone）与拾取物（pickup）时未释放其旧版 ID、导致这些 ID 无法复用的问题。[#1231](https://github.com/openmultiplayer/open.mp/pull/1231)
- 更新了 Pawn，修复其对打包字符串（packed string）执行 `memcpy` 与 `fwrite` 的问题，并修正了旧版服务器端游戏文本组件中的预设值。[#1180](https://github.com/openmultiplayer/open.mp/pull/1180)

### NPC 相关改进

- 新增 `NPC_SetVehiclePos`、`NPC_SetVehicleRot`、`NPC_GetVehiclePos` 与 `NPC_GetVehicleRot` 原生函数。**行为变更：** `NPC_SetPos` 现在会将 NPC 从所在车辆中移出；若要在 NPC 乘坐时调整其位置，请改用车辆专用函数。[#1182](https://github.com/openmultiplayer/open.mp/pull/1182), [#1237](https://github.com/openmultiplayer/open.mp/pull/1237)
- 修复了 NPC 车辆在坡道上行驶时显得扁平或出现瞬移的问题，并改进了车辆移动的同步。[#1249](https://github.com/openmultiplayer/open.mp/pull/1249), [#1280](https://github.com/openmultiplayer/open.mp/pull/1280)
- 修复了 `NPC_PutInVehicle` 将 NPC 放入船只后，其外观仍停留在徒步状态的问题。[#1236](https://github.com/openmultiplayer/open.mp/pull/1236)
- 修复了已死亡的 NPC 在流式加载（stream in）时仍呈站立姿态的问题；`NPC_Respawn` 现在会清除其死亡状态。[#1238](https://github.com/openmultiplayer/open.mp/pull/1238), [#1184](https://github.com/openmultiplayer/open.mp/pull/1184)
- 修复了未调用 `NPC_SetAmmo` 时 NPC 弹药无限的问题，修正了 `NPC_GetSkin` 的返回值，并修复了 `NPC_SetAngleToPos` 计算出的角度。[#1165](https://github.com/openmultiplayer/open.mp/pull/1165), [#1182](https://github.com/openmultiplayer/open.mp/pull/1182), [#1252](https://github.com/openmultiplayer/open.mp/pull/1252)
- 改进了 NPC 在路径节点间距较短时的移动表现，并避免零时长（zero-time）的节点切换在同一 tick 内反复执行。[移动逻辑调整](https://github.com/openmultiplayer/open.mp/commit/d39310858caa62557545a93e59a917ea417ca0d9)、[切换次数限制](https://github.com/openmultiplayer/open.mp/commit/958349e44a9f122a9182bd380e493b5bf1b5911b)
- 修复了 NPC 的清理流程，以及可选组件缺失或正在卸载时的若干崩溃问题。[#1175](https://github.com/openmultiplayer/open.mp/pull/1175), [#1182](https://github.com/openmultiplayer/open.mp/pull/1182)

### 构建与部署

- 构建系统迁移至 **Conan 2**，并新增了面向 Windows、Linux 与 macOS 的专门[构建指南](https://github.com/openmultiplayer/open.mp/blob/master/BUILD.md)。[#1233](https://github.com/openmultiplayer/open.mp/pull/1233), [#998](https://github.com/openmultiplayer/open.mp/pull/998)
- 新增 macOS ARM 构建支持，并修复了在新版微软工具链下的 Windows 兼容性问题。[#1234](https://github.com/openmultiplayer/open.mp/pull/1234), [#1235](https://github.com/openmultiplayer/open.mp/pull/1235), [#1166](https://github.com/openmultiplayer/open.mp/pull/1166)
- 修复了 32 位 Docker 运行镜像缺少启动 `omp-server` 所需库文件的问题。[#1263](https://github.com/openmultiplayer/open.mp/pull/1263)
