## 变更内容

### 游戏内与客户端功能

- 让游戏内启动器覆盖层更加顺滑可靠，窗口被重新创建时亦然。
- 改进与 ENB 及其他画面模组的兼容性。
- 修复了部分环境下启动画面（splash screen）图片显示异常的问题。
- 修复了部分自定义纹理在名称较长时无法加载的问题。
- 改进了昵称或密码含特殊字符时，从游戏内启动器发起连接的表现。
- 提升了加入或重连服务器、收到不完整服务器响应以及关闭游戏时的稳定性。
- 减少了游戏运行与覆盖层渲染过程中的一些不必要开销。

### 启动器改进

- 在“高级”设置中新增**模型缓存目录**选项，提供文件夹选择器，并在 Windows 上默认指向 SA-MP 的缓存路径。
- 新增最多五个最近使用昵称的历史记录，可在主窗口与加入服务器提示中直接选用。
- 新增 `--no-omp` 命令行选项，可在启动时不注入 open.mp 客户端。
- 新增亚美尼亚语、韩语与保加利亚语翻译；扩充并修正了西班牙语、立陶宛语、格鲁吉亚语、意大利语与塞尔维亚语翻译。
- 修复了为单个服务器修改过的昵称在加入提示中被重置的问题，并在切换 SA-MP 版本时保留这些昵称。
- 修复了从服务器右键菜单连接设有密码的服务器的问题。
- 对游戏内连接消息中的昵称与密码进行编码，使特殊字符能够被正确处理。
- 修复了命令行连接带连字符主机名的问题：启动前会先将其解析为 IPv4 地址。
- 修复了 SA-MP ping 查询的载荷，并对过短而无法解析的响应做了防护。
- 恢复了加载界面之后的主窗口尺寸，重新加载后同样有效。
- 游戏内启动器跳过更新检查，并改进了下载信息与插件信息的回退选取逻辑。
- 游戏 IPC 监听器改为按需启动，改进了客户端连接的清理，并将覆盖层窗口 ID 发送给游戏客户端。
- 改进了游戏可执行文件的启动方式：校验其路径、设置游戏目录，并断开其标准输入与输出。
- 改进了日志记录：依次尝试可执行文件同目录的日志文件、本地应用数据目录，最后回退到标准错误输出。
- 服务器右键菜单的配色会随主题变化同步更新，移除了服务器列表中的焦点描边，并让“高级”设置的按钮样式与“常规”设置保持一致。
- 安装程序改为下载 WebView2 引导程序（bootstrapper）。
- 修复了外部服务器对话框的相关问题。
