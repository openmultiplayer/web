open.mp 启动器

在 open.mp 和 SA-MP 服务器上游玩《侠盗猎车手：圣安地列斯》多人联机。

v1.7.0最新

亮点

  • 游戏内覆盖层更加顺滑，与 ENB 及各类画面模组的兼容性也得到改善
  • 新增模型缓存目录设置与最近使用昵称的历史记录
  • 连接与重连更可靠，客户端稳定性进一步提升
  • 新增亚美尼亚语、韩语与保加利亚语翻译，并更新了其他多种语言
查看完整更新日志

变更内容

游戏内与客户端功能

  • 让游戏内启动器覆盖层更加顺滑可靠，窗口被重新创建时亦然。
  • 改进与 ENB 及其他画面模组的兼容性。
  • 修复了部分环境下启动画面（splash screen）图片显示异常的问题。
  • 修复了部分自定义纹理在名称较长时无法加载的问题。
  • 改进了昵称或密码含特殊字符时，从游戏内启动器发起连接的表现。
  • 提升了加入或重连服务器、收到不完整服务器响应以及关闭游戏时的稳定性。
  • 减少了游戏运行与覆盖层渲染过程中的一些不必要开销。

启动器改进

  • 在“高级”设置中新增模型缓存目录选项，提供文件夹选择器，并在 Windows 上默认指向 SA-MP 的缓存路径。
  • 新增最多五个最近使用昵称的历史记录，可在主窗口与加入服务器提示中直接选用。
  • 新增 --no-omp 命令行选项，可在启动时不注入 open.mp 客户端。
  • 新增亚美尼亚语、韩语与保加利亚语翻译；扩充并修正了西班牙语、立陶宛语、格鲁吉亚语、意大利语与塞尔维亚语翻译。
  • 修复了为单个服务器修改过的昵称在加入提示中被重置的问题，并在切换 SA-MP 版本时保留这些昵称。
  • 修复了从服务器右键菜单连接设有密码的服务器的问题。
  • 对游戏内连接消息中的昵称与密码进行编码，使特殊字符能够被正确处理。
  • 修复了命令行连接带连字符主机名的问题：启动前会先将其解析为 IPv4 地址。
  • 修复了 SA-MP ping 查询的载荷，并对过短而无法解析的响应做了防护。
  • 恢复了加载界面之后的主窗口尺寸，重新加载后同样有效。
  • 游戏内启动器跳过更新检查，并改进了下载信息与插件信息的回退选取逻辑。
  • 游戏 IPC 监听器改为按需启动，改进了客户端连接的清理，并将覆盖层窗口 ID 发送给游戏客户端。
  • 改进了游戏可执行文件的启动方式：校验其路径、设置游戏目录，并断开其标准输入与输出。
  • 改进了日志记录：依次尝试可执行文件同目录的日志文件、本地应用数据目录，最后回退到标准错误输出。
  • 服务器右键菜单的配色会随主题变化同步更新，移除了服务器列表中的焦点描边，并让“高级”设置的按钮样式与“常规”设置保持一致。
  • 安装程序改为下载 WebView2 引导程序（bootstrapper）。
  • 修复了外部服务器对话框的相关问题。

v1.6.1

杀毒软件误报

部分杀毒软件可能将 open.mp 启动器误报为病毒。此为误报。本启动器是开源软件，可安全使用。若受影响，请将 open.mp 启动器的安装文件夹添加到你杀毒软件的排除列表中。

亮点

  • 游戏内服务器浏览器 (F9)：无需离开游戏即可浏览、切换和重新加入服务器
  • 导入和导出你喜爱的服务器列表，支持拖放重新排序
  • 支持自定义游戏可执行文件名
  • 自动选择客户端版本，并可针对每个服务器选择客户端版本

变更内容

游戏内与客户端功能

  • 新增游戏内服务器浏览器（按 F9 键），无需离开游戏即可浏览服务器列表，切换或重新加入服务器。
  • 新增自定义启动画面。
  • 在游戏内暂停菜单中直接添加了 open.mp 设置。
  • 在 open.mp 设置中添加了用于切换 Discord 状态（及其他状态指示器）的选项。
  • 改进了 Discord 状态处理，并修复了错误的 IP 报告。
  • 修复了与重连逻辑和 open.mp 协议相关的多个问题。
  • 修复了多个SA-MP 崩溃场景，提升了整体稳定性。

启动器改进

  • 在整个启动器中大幅提升了稳定性和性能。
  • 在 Rust 和 TypeScript 两端对代码库进行了大规模重构，以提升长期可维护性。
  • 显著改进了服务器查询机制，以提升效率和防止垃圾请求。
  • 为收藏的服务器添加了拖放重新排序功能。
  • 改进了Windows 7 兼容性。
  • 安装程序现在捆绑了 WebView2 安装程序，简化了设置流程。
  • 从“高级”设置选项卡中移除了 Discord 状态设置。
  • 在“高级”设置中添加了支持自定义游戏可执行文件名的选项。
  • 添加了导入和导出收藏服务器列表的功能。
  • 如果尚未安装 SA-MP，可自动选择合适的客户端版本。
  • 新增了按服务器选择客户端版本的功能。
  • 添加了大量有意义的日志信息，以改进诊断和支持。
  • 使用快速连接时，为有密码保护的服务器添加了加入提示。
  • 为大多数 API 添加了API 超时，以提高响应速度和可靠性。

错误修复与用户体验改进

  • 修复了文件缺失（特别是字体文件）时的文件复制问题。
  • 修复了服务器数据在重启应用程序后仍被缓存的问题。
  • 修复了主题切换故障。
  • 修复了按服务器设置的昵称输入故障。
  • 修复了排序箭头方向错误的问题。
  • 修复了搜索输入未包含游戏模式文本的问题。
  • 改进了服务器主机名解析。
  • 改进了权限处理和面向用户的消息提示。
  • 修复了网页 URL 验证问题。
  • 修复了更改语言后设置选项卡标题不更新的问题。
  • 为服务器查询请求添加了频率限制，以防垃圾请求。
  • 更新并扩充了多种语言的本地化文件。
