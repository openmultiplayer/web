Recursos

Herramientas​

  • Community Compiler - Una versión actualizada del compilador, con varias mejoras y arreglos.
  • sampctl - Administrador de paquetes para instalar librerías y ejecutar tu servidor.
  • Plugin Runner - Herramienta para ejecutar una versión liviana del servidor directamente desde la caja de comandos (sin precisar server.cfg). Para probar/experimentar con plugins.
  • Plugin Boilerplate - Facilitar un plugin con boilerplate.
  • SA:MP Plugin Template Library - Crea tus propios plugins fácil y rápido con esta biblioteca de plantillas.
  • SA-MP Fiddle - Un lugar donde probar tus scripts (snippets, PoC, debugging, etc) y compartilo con otros.
  • Pawn Syntax - Sublime - Función de autocompletar lenguaje Pawn para Sublime Text.
  • Pawn Syntax - Visual Marketplace - Función de autocompletar lenguaje Pawn para Visual Studio Code.
  • SA-MP Zone Editor - Editor de zonas para generar areas y demás.
  • SA-MP Map Editor - Editor de mapas para SA:MP.

Librerias​

  • SA:MP stdlib - Includes por defecto actualizados, con valores constantes, documentados, y completos.
  • fixes.inc - Plug-and-play. Arreglos y optimización para un gran número de errores en los servidores de SA:MP. Plug And Play.
  • YSI - La más vieja, extensa, probada, y adaptada libería para SA:MP/Pawn, proveyéndonos un gran número de nuevas características del lenguaje y del juego.
  • amx_assembly - Acceso al bajo nivel del mismo script de Pawn.
  • md-sort - Ordena arrays multidimensionales en Pawn. Modifica los punteros internos de la matriz en lugar de copiar los datos.
  • indirection - Sistema para pasar punteros y llamar funciones indirectamente, con métodos abstractos para customizar llamadas.
  • code-parse.inc - Analizar y customizar código Pawn al momento de compilación.
  • strlib.inc - Funciones útiles para manipular strings en SA:MP.
  • extended-vehicle-information.inc - Una gran cantidad de valores de vehículos del singleplayer a una base de datos en SQLite.
  • sqlitei - API de alto nivel para las funciones SQLite de SA-MP.
  • weapon-config - Sistema de daños más coherente y sensible, con muchas novedades.
  • samp-geoip - Obtener información geográfica basado en una dirección IP.
  • weapon-data - Datos de armas personalizables y ajustados con precisión.
  • MySQL Prepared Statements - Emulando Prepared Statement para el plugin MySQL de PAWN.
  • samp-server-weapons - Armas totalmente controladas por el servidor.
  • actor_robbery - Inspirado en los robos de tienda de GTA V. ¡Actor_robbery.inc lo imita!
  • samp-aviation - Piloto automático para SA:MP.
  • samp-logger - Simple registrador estructurado que proporciona un conjunto simple de funciones para el registro y depuración.
  • TDW Recursion Scanner - Una biblioteca que encuentra las recursiones en el código.
  • easyDialog - Facilita el uso de diálogos en general.
  • mdialog - Sistema de diálogo moderno, similar a easyDialog.
  • Model Sizes Plus - Versión actualizada, avanzada y más precisa de los antiguos modelos.
  • physics.inc - Simule la física 2D y 3D (movimientos realistas, colisiones y mucho más).
  • samp-async-dialogs - Manejo asíncrono de diálogos con tareas PawnPlus.
  • speedcap.inc - Unas Librerias para controlar la velocidad de los vehículos.
  • SA:MP Command Guess - Un adivinador de comandos para SA:MP utilizando la función de distancia Levenshtein.
  • vending - Máquinas expendedoras del lado del servidor para SA-MP.
  • mathutil - Una lista de funciones matemáticas útiles.
  • rotations.inc - Una lista de funciones de rotación útiles de Nero_3D's rotations.inc.
  • SA-MP Distance Functions - Lista de funciones útiles de comprobación del distanciamiento.
  • New SA-MP callbacks - Una lista de nuevas funciones callback útiles.
  • Alternative Dialogs - Diálogos Textdraw con un nuevo diseño.
  • eSelection - Añade la posibilidad de crear menús dinámicos de selección de modelos en tus modos de juego SA-MP.
  • mSelection - Igual que eSelection, pero con otro estilo.
  • progress2.inc - Mostrar el tiempo, la vida, el combustible y demás cosas como una barra progresiva.
  • MV_Youtube.inc - API que convierte links de YouTube para streams de Audio.

Procesadores de Comandos​

  • izcmd.inc - Versión mejorada de ZCMD.
  • PawnCMD.inc - El procesador de comandos más rápido del oeste.
  • y_commands - Procesador de comandos de YSI Includes.

Plugins​

  • JIT - Una vez que tu código sea estable, utiliza esto para acelerarlo significativamente.
  • crashdetect - Herramienta de desarrollo para encontrar bugs durante el testeo.
  • Profiler - Plugin de perfil de rendimiento para el servidor SA-MP.
  • sscanf - Convierte strings en múltiples valores, enteros, flotantes, jugadores, etcétera.
  • MySQL - Enlaza tu servidor a un servidor MySQL.
  • streamer - Sobrepasa los límites de objetos y pickups.
  • nativechecker - Comprobación de nativos al iniciar el servidor.
  • FCNPC - Un plugin para servidores SA-MP que añade muchas capacidades a los NPC estándar existentes.
  • FileManager - Permite gestionar archivos y carpetas desde la carpeta raíz (no se limita al directorio del servidor scriptfiles con este plugin).
  • Pawn.Raknet - Permite analizar el tráfico de RakNet.
  • samp-precise-timers - Un plugin para SA-MP que proporciona temporizadores precisos, escrito en Rust.
  • PawnPlus - Amplía las posibilidades del lenguaje de scripting Pawn con nuevas construcciones, tipos de datos y técnicas de programación.
  • PAWN memory access - Permite asignar y liberar memoria del heap en PAWN.
  • Native Fallback - Complemento SA-MP que proporciona una implementación alternativa a los nativos no registrados.
  • YSF - Un Plugin cuyo propósito es extraer las máximas posibilidades del servidor, principalmente con edición de memoria y hooking.
  • SKY - Este plugin proporciona funciones de bajo nivel para que los scripts de Pawn puedan hacer cosas potentes.
  • Pawn.Regex - Añade soporte para expresiones regulares en Pawn.
  • pawn-scraper - Un potente plugin de scraper que proporciona una interfaz para utilizar html_parsers y selectores css en pawn.
  • TOTP - Permite utilizar la autenticación TOTP en un gamemode sa-mp.
  • DNS Plugin - Este plugin proporciona funcionalidad para búsquedas DNS y búsquedas DNS inversas.
  • MapAndreas - Permite cargar diferentes mapas de altura y comprobar la altura mínima para las coordenadas x,y.
  • ColAndreas - Crea una simulación del mundo de San Andreas. Utiliza la biblioteca Bullet Physics.
  • PathFinder - Permite calcular una ruta del punto A al B en el mapa de San Andreas.
  • Custom Query Flood Check - Escribir protecciones personalizadas contra query floods.
  • sampml - Conjunto de herramientas de aprendizaje automático simplificado y proyectos SAMP asociados (Detección de Aimbot).
  • TgConnector - Un plugin conector de telegram que ayuda a interactuar con bots de telegram a través de SA-MP.
  • Discord Connector - Enlaza tu servidor a un bot de Discord.
  • TSConnector - Te permite controlar un servidor Teamspeak3 desde tu script PAWN.
  • IRC Plugin - Permite la creación y gestión de bots IRC a través del servidor SA-MP.
  • pawn-requests - Proporciona una API para interactuar con APIs HTTP(S) con soporte para tipos de datos de texto y JSON.
  • pawn-redis - Acceso a una rápida base de datos en memoria y canales de mensajes asíncronos entre otros programas.
  • Chrono - Una moderna biblioteca Pawn para trabajar con fechas y horas.
  • Advanced SA NickName - Admite cualquier símbolo en el nombre de jugador.
  • SAMPSON - Un plugin JSON para SA-MP.

Plugins cliente-servidor​

  • SA-MP+ - Una modificación del cliente que utiliza el SDK de plugins de SA-MP para interactuar con el servidor y añadir nuevas funciones.
  • CHandling - Añade la posibilidad de asignar manejos de vehículos individuales modificando el comportamiento por defecto del juego.
  • SAMPVOICE - Implementación de sistemas de comunicación por voz en el lenguaje Pawn para servidores SA:MP.
  • KeyListener - Plugin cliente-servidor para rastrear la pulsación de cualquier tecla.
  • SAMP CEF - Complementos de cliente y servidor para SA:MP para integrar CEF.
  • SAMP_AC_v2 - SA:MP Anti-Cheat del lado del cliente.

Plugins criptográficos​

  • whirlpool - Algorítmo criptográfico Whirlpool para SA:MP.
  • samp-bcrypt - Un plugin de bcrypt para samp en Rust.
  • bcrypt - Plugin criptográfico Bcrypt para SA:MP.
  • samp-crypto - Una lista de funciones criptográficas como Argon2, Scrypt y Bcrypt para SA:MP.
  • SHA512 - Algorítmo criptográfico SHA512 para SA:MP.

GDK/SDK's​

Ahora puedes hacer tus scripts en otros lenguajes que no sean pawn sin ningun plugin usando open.mp. Ver esta entrada de blog.

  • sampsdk - Esto es lo mínimo que se necesita para desarrollar plugins.
  • sampgdk - Lenguaje C/C++ para escribir un gamemode para SA:MP
  • SampSharp - Soporte de lenguaje C# para escribir un gamemode para SA:MP
  • .NET Plugin - Soporte de lenguaje C# para escribir un plugin para SA:MP
  • sampgo - Soporte de lenguaje Go para escribir un gamemode/plugin para SA:MP
  • samp-node - Lenguaje Javascript/Typescript para escribir un gamemode para SA:MP
  • Shoebill Project - Soporte de lenguaje Java para escribir un gamemode para SA:MP
  • pySAMP - Lenguaje Python para escribir un gamemode para SA:MP
  • samp-rs - Soporte de lenguaje Rust para escribir un plugin para SA:MP
  • Yet Another Lua Plugin - Lenguaje Lua para escribir un gamemode para SA:MP
  • SAMPHP - Soporte de lenguaje PHP para escribir un gamemode para SA:MP
  • SA-MP S[D]K - Soporte de lenguaje D para escribir un gamemode para SA:MP
  • Kamp - Soporte de lenguaje Kotlin para escribir un gamemode para SA:MP

Game Modes​

  • Example Gamemode - Lista de modos de juego (gamemodes) que son compatibles con open.mp.
  • ScavengeSurvive - gamemode Survival Jugador contra Jugador (JcJ).
  • gta-open - Un modo de policías y ladrones basado en Los Santos.
  • SF-CnR - San Fierro Policías y Ladrones Gamemode para SA-MP.
  • Next Generation Roleplay - The Next Generation Gaming, LLC SA:MP gamemode.
  • SC-RP - Un gamemode de roleplay con soporte MySQL.

Filterscripts​

  • MapFix - Corrección de errores de texturas del mapa de GTA San Andreas.
  • SA:MP Animbrowse - Herramienta de navegación de animación para SA:MP.
  • IsPlayerUsingAndroid - Comprueba si un jugador es usuario de android.
  • Nickk's TextDraw Editor - Un editor TextDraw que tiene algunas características ricas.
  • Ultimate Creator - Editor de mapas avanzado con muchas funciones.
  • Fusez's Map Editor - Un editor de mapas en el juego para SA:MP.
  • Texture Studio - Este es un editor de mapas en el juego que te permitirá texturizar hasta el índice de material 15 (16 materiales), así como establecer el color para ese índice de material en los objetos.
