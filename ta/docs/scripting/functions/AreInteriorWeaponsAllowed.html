AreInteriorWeaponsAllowed

எச்சரிக்கை

செயல்பாடு என்பது omp v1.1.0.2612 பதிப்பில் சேர்க்கப்பட்டது. இது முந்தைய பதிப்புகளில் இயங்காது!

Description​

Can weapons be used in interiors?

Returns​

true: Allowed.

false: Not allowed.

Examples​

if (AreInteriorWeaponsAllowed())
{
    // Do something
}

Related Functions​

  • AllowInteriorWeapons: Toggle whether the usage of weapons in interiors is allowed or not.
